# Multi-Dimensional Logger Analyzer

GPSロガーやセンサーロガーが出力するCSVログを読み込み、時系列グラフと地図（軌跡）を
連動させて解析するためのWindowsデスクトップアプリです。

## 概要

- 複数のCSVファイル（例: 1日1ファイルのGPSロガー出力）をフォルダごと読み込み、
  時系列として結合して解析できます。
- 列名・単位が定義されていないヘッダーなしCSVでも、列マッピング設定でGUIから
  列名・単位を割り当てられます。
- 大量データ（数万〜数十万行）でも軽快に扱えるよう、表示時にmin/max/mean帯への
  自動間引き（ダウンサンプリング）を行います。
- 読み込んだデータはキャッシュとして保存・復元でき、次回以降のCSV再パースを省略できます。

## 主な機能

### グラフ表示（3モード）

| モード | 内容 |
|---|---|
| 通常モード | 横軸=時刻の連続時系列。間引き時はmin/max帯＋平均線で表示 |
| 日変化モード | 横軸を0:00〜23:59に畳み込み、複数日を重ね合わせて表示。出現頻度をヒートマップ（色の濃淡）で可視化し、時間帯ごとの傾向を把握しやすくしています |
| 累積出現度数モード | 値の小さい順に並べ、0.001%〜99.999%の対称対数軸（確率紙のような見た目）で累積出現度数を表示 |

- 列ごとにプロット色・軸ラベル・目盛り間隔をカスタマイズ可能です。
- 通常モードではグラフをドラッグして範囲選択でき、その区間の統計値・相関係数を再計算できます。

### 地図表示（GPS列がある場合）

- 緯度・経度列が認識されると、軌跡を地図上に赤い点として自動表示します。
- 背景地図には国土地理院タイルを使用し、白黒（グレースケール）表示にして軌跡を見やすくしています。
- 初期表示は、軌跡データ全体が収まる範囲に自動でズームします（異常なGPS値混入時などのフォールバックとして、最大でも日本本土程度の範囲に収まるよう制限しています）。

### グラフ⇔地図の双方向連携

- グラフ上をクリックすると、対応する時刻のGPS位置に地図上のピンが移動します。
- グラフをズーム/パンすると、地図上に表示される軌跡点がその時間帯のものだけに絞り込まれます。
- 逆に地図をズーム/パンすると、その表示範囲に写っている軌跡点の時間帯にグラフの表示範囲が合わせて絞り込まれます。
- 「表示範囲(ズーム)に応じてY軸を自動調整」をONにすると、上記の絞り込みに合わせてグラフの縦軸（データ軸）もその区間のデータに合わせて自動的にスケーリングされます（チェックボックスでON/OFF切り替え可能）。

## 動作要件

- Windows 10 / 11（開発・動作確認はWindows環境を主対象としています）
- Python 3.10以降を推奨
- 主な依存パッケージ（詳細は`requirements.txt`参照）
  - PyQt6, PyQt6-WebEngine
  - pyqtgraph
  - numpy, pandas
- **地図タイルの表示にはインターネット接続が必要です**（国土地理院のタイルサーバーから取得するため）。
  地図の枠組み自体（Leaflet本体）はローカル同梱のため、タイル画像が取得できない場合でも
  軌跡データ自体は表示されます。
  - 一部のセキュリティソフト（Norton等）は、地図描画に使うQtWebEngineの内部プロセスからの
    通信を「素性不明な通信」として遮断することがあります。地図タイルだけが表示されない場合は、
    お使いのセキュリティソフトのWeb保護／侵入防止機能の設定をご確認ください。

## セットアップ・起動

```bash
pip install -r requirements.txt
python main.py
```

Windows環境で`PyQt6-WebEngine`のインストールに失敗する場合は、pipを最新化してから
再実行してください（`pip install --upgrade pip`）。

## 使い方（簡易）

1. 左パネルの「フォルダを読み込み」で、CSVファイルが入ったフォルダを選択します。
2. ヘッダーなしCSVの場合は、「列マッピング設定」で列名・単位を設定し「マッピングを適用」を押します。
3. 「表示項目」で表示したい列を選択します（緯度・経度列が認識されると地図表示が自動的に有効になります）。
4. グラフ表示モード（通常／日変化／累積出現度数）を切り替えて確認します。
5. 通常モードでは、グラフ上をドラッグすると、その範囲の統計値・相関係数が再計算されます。
6. 「グラフ外観設定」で、列ごとの色・軸ラベル・目盛り間隔、Y軸自動調整のON/OFFをカスタマイズできます。
7. 「出力」から、クリップボードへのコピー（画像）や印刷（PDF出力含む）が行えます。
8. 一度読み込んだデータは「キャッシュとして保存」でファイル化しておくと、次回は「キャッシュから読み込み」で
   CSVの再パースなしに高速に復元できます。

## Windows用配布パッケージのビルド（PyInstaller）

`build/app.spec`にビルド設定を用意しています。

```bash
pip install pyinstaller
pyinstaller build/app.spec
```

`dist/MultiDimensionalLoggerAnalyzer/` フォルダ一式が生成されます。QtWebEngineの
付随リソースが多いため、単一exe化（`--onefile`）ではなくフォルダ形式でビルドしています
（フォルダごと配布してください）。1つのセットアップファイルとして配布したい場合は、
Inno SetupやNSIS等のインストーラ作成ツールで、このフォルダをラップすることを想定しています。

## 既知の制約

- 複数列の同時重ね描き（現状は1列表示のみ）は未対応です。
- 日変化モードは日付情報を保持しないため、グラフ⇔地図の時刻連動・範囲選択からの統計再計算の対象外です（通常モードのみ対応）。
- EMF形式でのクリップボード出力は非対応です（Windows固有形式でクロスプラットフォームなQt APIから生成できないため）。代わりに高解像度PNG／SVGでのコピーに対応しています。
- Windows以外のOSでの動作確認は行っていません。
